Video #1 MIT Lisansı

upstash/context7

Desteklenen yapay zeka kodlama araçlarına (Cursor, Claude Code, VS Code vb.) güncel ve sürüme özel kütüphane dokümantasyonu sağlamaya yardımcı olur. Prompt sonuna eklenen yönlendirme ile ilgili doküman bağlamını asistana iletir.

Kurulum Komutu
npx ctx7 setup
⚙️ Gereksinim: Node.js 22.13 veya üzeri. (Kaldırmak için: npx ctx7 remove)
Demo Promptu (Videoda Denenen)
Create a Next.js proxy that checks for a valid JWT in cookies and redirects unauthenticated users to `/login`. use context7
💡 İpucu: Prompt sonundaki use context7 ifadesi yönlendirmeyi tetikler.
