upstash/context7

Yapay zeka kodlama asistanlarının (Cursor, Claude Code, VS Code vb.) güncel olmayan kütüphane dokümanları ve uydurma API cevapları üretmesini engeller. Prompt sonuna eklenen komutla AI'a sürüme özel güncel dokümantasyonu iletir.

Kurulum Komutu
npx ctx7 setup
⚙️ Gereksinim: Node.js 22.13 veya üzeri. (Kaldırmak için: npx ctx7 remove)
Demo Promptu (Videoda Kullanılan)
Create a Next.js proxy that checks for a valid JWT in cookies and redirects unauthenticated users to `/login`. use context7
💡 İpucu: Prompt sonundaki use context7 ifadesi asistanı tetikler.
